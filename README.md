# Lo-Fi-Workspace

☕ Lo-Fi Workspace (Claude-Style)
To minimalistyczny, interaktywny pulpit nawigacyjny typu "Lo-Fi Workspace", zaprojektowany z myślą o produktywności i skupieniu. Interfejs jest inspirowany estetyką Claude AI – czysty, nowoczesny i przyjemny dla oka.

🚀 Główne funkcje
Pomodoro Timer: Wbudowany czasomierz (25 min) z systemem nagradzania XP za ukończone sesje skupienia.

System XP: Prosta grywalizacja – zbieraj punkty za kończenie zadań i sesje Pomodoro, aby awansować na kolejne poziomy.

Interaktywny Kalendarz: Zarządzaj swoim harmonogramem, dodawaj wydarzenia i przypisuj im kategorie (Praca, Nauka, Chill).

Notatnik dzienny: Szybki dostęp do notatek z automatycznym zapisem w przeglądarce (localStorage).

Klimatyczne scenerie: Zmieniaj nastrój pulpitu (Domyślny, Deszcz, Noc) z dopasowanymi dźwiękami otoczenia i animacją deszczu.

Pasek wyszukiwania: Szybkie wyszukiwanie w Google bezpośrednio z pulpitu.

Integracja pogodowa: Podgląd aktualnej temperatury dla Warszawy.

🛠️ Technologie
Projekt oparty jest na czystych technologiach webowych (tzw. Vanilla Stack):

HTML5

CSS3 (z wykorzystaniem Flexbox, Grid oraz zmiennych CSS)

JavaScript (ES6+) (z wykorzystaniem localStorage do zapisu danych użytkownika)

📦 Jak uruchomić projekt
Sklonuj repozytorium lub pobierz pliki na swój komputer.

Upewnij się, że pliki index.html, style.css oraz script.js znajdują się w tym samym folderze.

Otwórz plik index.html w dowolnej nowoczesnej przeglądarce internetowej.

Opcjonalnie: Aby projekt działał w pełni poprawnie (np. dźwięki), najlepiej uruchomić go na lokalnym serwerze (np. przy użyciu rozszerzenia Live Server w VS Code).

🎨 Estetyka
Interfejs został zaprojektowany z myślą o minimalizmie:

Paleta kolorów: Inspirowana Claude AI (ciepłe beże, subtelne szarości, czysta biel).

Typografia: Systemowe kroje pisma dla maksymalnej czytelności.

📝 Uwagi techniczne
Dane takie jak wydarzenia, notatki oraz poziom XP są przechowywane w pamięci Twojej przeglądarki (localStorage). Nie wymagają zewnętrznej bazy danych.

Animacja deszczu wykorzystuje element HTML5 <canvas>.
